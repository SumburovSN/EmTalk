# EmTalk

**EmTalk** — прототип ИИ-помощника для поддержки сотрудников в повседневных рабочих ситуациях.

Цель проекта — помочь человеку справиться с рабочими затруднениями, восстановить концентрацию, определить приоритеты и выбрать следующий небольшой шаг.

## Текущий статус

Реализован первый локальный прототип:

- **n8n** — оркестрация workflow.
- **Ollama** — локальный запуск языковой модели.
- **Qwen 2.5:3b** — генерация ответов.
- **Webhook API** — приём сообщений через HTTP POST и возврат ответа в JSON.

Прототип работает локально на компьютере разработчика.

## Структура проекта

```text
EmTalk/
├── README.md
├── workflows/    # Экспортированные workflow n8n
├── scripts/      # Скрипты запуска и остановки
└── config/       # Документация по конфигурации
```

## Локальное окружение

- ОС: Ubuntu Linux
- Docker Desktop
- n8n Community Edition
- Ollama
- Модель: `qwen2.5:3b`

n8n доступен по адресу: http://localhost:5678

Локальный API Ollama: http://localhost:11434

## Запуск и остановка

Для запуска и остановки компонентов используются скрипты из каталога `scripts/`.

Перед запуском n8n необходимо убедиться, что Docker Desktop работает.

Инструкции по запуску и остановке будут дополняться по мере развития проекта.

## План развития

1. Улучшить системный промпт и качество ответов EmTalk.
2. Реализовать полноценный диалог с учётом истории сообщений.
3. Разработать backend API.
4. Создать веб-интерфейс на React.
5. Продумать безопасную конфигурацию, хранение данных и поддержку нескольких языков.

## Принципы проекта

- Поддерживать человека без давления и избыточных советов.
- Помогать выбирать конкретные, выполнимые следующие шаги.
- Оставлять окончательный выбор за пользователем.
- По возможности использовать локальную обработку данных.
- Не хранить лишние персональные и чувствительные данные.
